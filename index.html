How "Access needed" works
Access needed shows the minimum Microsoft Entra built-in role for each task. Global Administrator and Security Administrator are not repeated where a narrower role suffices. If your tenant has activated Microsoft Defender XDR Unified RBAC (URBAC), those custom roles override Entra permissions inside the Defender portal — map each Entra role to the equivalent permissions in the Defender unified RBAC permissions reference ↗.
